## Building for agents

[pi-subagent](https://github.com/eggmasonvalue/pi-subagent) - Aims to be the most LLM-empowering pi subagent - intentionally designed subagent to provide a thin yet capable interface that puts the main agent in control - with human and agent observability, steerability and model policy

[antigravity-agents](https://github.com/eggmasonvalue/antigravity-agents) - custom google antigravity main agents that offers nearly the same functionality with up to 55% and 70% fewer tokens in the system prompt and defensive guidelines to compensate for poor run_command tool design for significantly cleaner context through-session

[secstack](https://github.com/eggmasonvalue/secstack) - **Doman specific harness** for full-stack US-listed company research - custom system prompt, tools and a set of composable skills. 7500+ lines within skills yet very thin surface to the agent and active context footprint due to meticulously followed progressive disclosure

[pi-system-prompt-viewer](https://github.com/eggmasonvalue/pi-system-prompt-viewer) - observe exactly what is in your context in pi with a. provider neutral system prompt and tools b. the full LLM provider-specific payload at any point 

[jules-autoresearch](https://github.com/eggmasonvalue/jules-autoresearch) - **agent loop engineering** - autoresearch AI agent skill for long-running agent loops delegated to Google Jules coding agent in the cloud

[tracky-mcp](https://github.com/eggmasonvalue/tracky-mcp.git) - agent-first smart body scale companion - an MCP server for tracky(Yolanda/Feelfit) smart body scales with an agent skill to interpret that data
