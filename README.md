## Building for agents; Clean Context Club member

[pi-subagent](https://github.com/eggmasonvalue/pi-subagent) - Aims to be the most LLM-empowering [pi](pi.dev) subagent extension - intentionally misses out on typical subagent features yet provides uncommon ones - all to provide a thin capable tool that stays true to philosophy

[antigravity-agents](https://github.com/eggmasonvalue/antigravity-agents) - custom google antigravity main agents that offers nearly the same functionality with up to 51% fewer tokens in the system prompt

[secstack](https://github.com/eggmasonvalue/secstack) - fully custom pi config for full-stack US-listed company research - custom system prompt, tools and a set of composable skills. 7500+ lines within skills yet very thin surface to the agent due to meticulously followed progressive disclosure

[pi-system-prompt-viewer](https://github.com/eggmasonvalue/pi-system-prompt-viewer) - observe exactly what is in your context in pi with a. provider neutral system prompt and tools b. the full LLM provider-specific payload at any point 

[jules-autoresearch](https://github.com/eggmasonvalue/jules-autoresearch) - autoresearch AI agent skill for long-running agent loops

[tracky-mcp](https://github.com/eggmasonvalue/tracky-mcp.git) - an MCP server for tracky(Yolanda/Feelfit) smart body scales
